# NewLife.AB 需求文档

**项目**：NewLife.AB — 罗克韦尔 / Allen-Bradley Logix 通信协议库  
**版本**：v1.0  
**日期**：2026-11-11  
**状态**：首发。范围是 EtherNet/IP 上的 Logix 符号标签

---

## 1. 目标

做一个纯 .NET 的 AB PLC 通信库，让上位机用标签名读写 ControlLogix / CompactLogix，并接到 NewLife.IoT。

| 维度 | 要求 |
|------|------|
| 协议 | EtherNet/IP TCP，默认端口 44818。CIP 未连接消息为主，需要时 Forward Open |
| 控制器 | Logix 5000 家族的符号标签。不把 SLC / PLC-5 / MicroLogix 说成已支持 |
| 数据 | BOOL、SINT、INT、DINT、LINT、USINT、UINT、UDINT、ULINT、REAL、LREAL、STRING，以及这些原子类型的一维数组 |
| API | 同步 + 异步，`ConfigureAwait(false)`，类型化读写，断线退避重连 |
| 测试 | `LogixServer` 模拟器。`dotnet test` 不需要真实 PLC |
| 依赖 | 协议实现只用 BCL 和 NewLife 基础库 |
| 工程 | 对齐 NewLife.Omron：类库、Test 控制台、XUnit、中文文档、MIT |

包名、程序集、根命名空间都是 `NewLife.AB`。驱动类型是 `AbDriver`、`AbParameter`、`AbNode`。

## 2. 用户和场景

- 上位机和 SCADA 要读 Logix 标签
- 边缘网关把 AB PLC 的点接到星尘或 IoT 平台
- 没有控制器时，用模拟器把采集程序跑起来

典型调用是：指定 IP、端口、槽号和标签名，读一个 DINT 或写一个 BOOL。

## 3. 功能范围

### 3.1 通信

1. 建立 TCP，发送 Register Session（协议版本 1），保存会话句柄
2. 默认把 CIP 请求放进 Unconnected Send，路由为背板端口 1 加槽号
3. `RoutePath` 可写成 `1,2` 或 `2,192.168.1.10,1,0`
4. `RouteToSlot = false` 时，CIP 直接放在 SendRRData 的未连接数据项里
5. `ConnectedMessaging = true` 时，注册会话后 Forward Open，标签请求改走 SendUnitData，关闭时 Forward Close
6. ListIdentity 与身份对象 Get_Attributes_All
7. 封装状态 0x0064 时重新注册；TCP 断开时按 1s、2s、3s 重连
8. 应答上下文必须与请求一致

### 3.2 标签

1. 读、写原子标签和一维数组
2. `Program:程序名.标签`
3. 结构的原子成员，例如 `Motor.Speed`
4. `标签.位号` 用 Read Modify Write 改单个位
5. 一次读多个标签（Multiple Service Packet），按大约 450 字节分批
6. 应答状态 0x06 时自动分段读完
7. 写入超过 `WriteFragmentSize`（默认 400 字节）时分段写
8. STRING：先取得结构句柄，再按 LEN + DATA 写入。默认容量 82

### 3.3 驱动和控制台

1. `AbDriver` 打开、读、写、关闭。多个节点共享一个连接，用引用计数释放
2. 参数至少包含 `地址:端口` 和槽号
3. 点位长度按字节，再按类型换成元素个数
4. Test 控制台接受主机、端口、槽号、标签，以后可以直接对真实 PLC 运行

### 3.4 模拟器

1. 随机端口或指定端口
2. 覆盖注册会话、身份、未连接发送、标签读写、分段、位修改、多服务、Forward Open / Close
3. 可关闭自动建点、指定槽号、强制 CIP 状态、作废一次会话、缩小应答以触发分段、断开已接入的客户端

## 4. 不在首发范围

| 项目 | 处理 |
|------|------|
| SLC / PLC-5 / MicroLogix 的 PCCC、DF1 | 不实现。`PcccLegacy` 保留服务码 0x4B，调用即失败 |
| UDT 模板下载和整结构解析 | 不做。成员路径若指向原子量，按原子量读写 |
| 符号对象 0x6B 的实例浏览 | 不做。调用方提供标签名 |
| Large Forward Open 0x5B | 不做。显式连接限制在 500 字节，大数据走分段服务 |
| 模拟器中的多维数组存储 | 不做。路径仍然编码多维下标 |

这些限制要写在 README 和架构说明里，不能在文档中把它们写成已经支持。

## 5. 地址格式

```
[类型:]标签[.成员][下标][.位]
Program:程序名.标签[下标]
```

- 冒号前面如果是已知类型名，就是类型提示；`Program:` 不是类型
- 最后一段如果全是数字，就是位号
- 下标从 0 开始，可以写成 `Tag[1]` 或 `Tag[1,2]`
- 空地址、未闭合的括号、空白标签名要拒绝

## 6. 错误

| 情况 | 行为 |
|------|------|
| 连接被拒绝或超时 | 抛出异常，不假装已连接 |
| 标签不存在 | `CipException`，通用状态 0x05 |
| 路由或槽号不对 | 通用状态 0x04 |
| 类型不一致 | 扩展状态 0x2107 |
| 下标超出 | 扩展状态 0x2105 |
| 写入 Decimal 等未支持的 CLR 类型 | `ArgumentException`，不需要已经连上 PLC |
| 调用 PCCC 入口 | `NotSupportedException` |
